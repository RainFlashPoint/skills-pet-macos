# Skills Pet macOS v0.1.1

This update focuses on local pet customization and better project organization.

## Highlights

- Added support for local pet packs under `~/SkillsPetLite/pets/<pet-name>/`
- Sprite loading now falls back cleanly to the built-in `cat-sprites/` assets
- Added a helper script for splitting generated walk sheets into individual frames
- Updated README with the local pet pack workflow

## What Changed

- `Sources/AppDelegate.swift`
  - Added local pet pack discovery and sprite alias resolution
  - Kept the default sprite set as a fallback
- `Sources/PetView.swift`
  - Improved click reactions and edge-rest behavior
  - Adjusted pose progression for more natural idle flow
- `scripts/split_generated_walk_sheet.py`
  - Added a reusable helper for generating `cat_walk_gen_*.png` frames

## Notes

- The feature is intentionally simple and file-based
- Missing frames are allowed and will fall back to the default cat
- This release is still macOS-only
