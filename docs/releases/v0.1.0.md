# Skills Pet macOS v0.1.0

Initial public release of the lightweight macOS desktop pet prototype.

## Highlights

- Native `Swift + AppKit` macOS desktop pet
- Transparent floating window with drag interaction
- Status bar controls and right-click quick menu
- Basic pose system with idle, sit, walk, recline, and sleep states
- Local Skills Hub / Catalog integration

## Included in this release

- Xcode project for local development
- Shell build script for packaging the app
- Sprite assets and source materials
- Project README, MIT license, and release workflow docs

## Notes

- This release targets macOS only
- Some local integration features depend on files on the local machine
- The app is still a prototype and will continue to evolve
